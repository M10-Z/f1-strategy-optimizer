# F1 历史策略研究工作台 · 一页启动说明

**用途：历史冻结证据复盘、明确假设下的多车策略比较。不是实时比赛助手，不承诺真实策略收益。**

1. 解压启动包到普通可写文件夹，建议路径不用中文空格。需要 **Python 3.12**（本轮测试版本），浏览器使用 Chrome/Edge/Firefox。
2. Windows 双击 `启动.cmd`；macOS/Linux 在该目录执行 `bash start.sh`。首次会建立本地 `.venv` 并按 `requirements-runtime.txt` 安装确切版本，需要网络；后续使用缓存示例无需联网。脚本仅连接标准 Python 包源，不修改网络策略。
3. 浏览器打开 **http://127.0.0.1:8765**。端口占用时执行 `.venv/bin/python start.py --port 8770`（Windows 为 `.venv\Scripts\python.exe`）。终端 Ctrl+C 退出。
4. 默认真实缓存为 2023 巴林、Leclerc、15:18 UTC。先查看各证据的年龄/来源、分段候选或弃权原因，再检查参与车辆、手工条件、目标名次和对手策略。确认后运行；未知输入须明确补充假设，不能当作观测。
5. “揭晓”才显示事实结果。导出 JSON 保存证据、假设及模拟；离线复现：`.venv/bin/python -m f1_strategy_optimizer.workbench_replay 下载文件.json`。修改数字后必须重新运行。

**输入与边界**：时间年龄按事件到历史 cutoff 计算；源发布时间未验证。间距/天气/赛会状态各有期限，未知值不补零。分段候选取最近三圈，转换后需要重新积累；它不保证比旧基线更准。降雨信号不证明路面湿干。库存、车辆活动状态、同圈投影、对手行为及概率均未完整核实；界面不输出校准概率。模型名次仅在选择的车阵和模拟终点成立。

**包内内容**：完整 Python 源码与 wheel、锁定运行依赖、启动脚本、三个可运行的真实冻结缓存时点、验证报告、源码版本与 SHA256 清单、MIT 代码许可。原始大型数据及完整历史另存恢复包。本包不含 Python 解释器或第三方依赖 wheel；首次安装若被网络阻断，请保留实际错误，不要跳过锁定依赖。
