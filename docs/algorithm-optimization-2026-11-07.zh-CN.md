# 确定性求解器优化与等价验证（2026-11-07）

本轮只优化单车确定性 DP 的重复计算，不替换工作台的默认圈时预测器，不改变多车模拟器、真实数据、冻结预测或历史评分。目标是相同模型和约束得到相同结果、更少搜索开销；不是提高预测精度或证明真实进站收益。

## 修改及正确性依据

原求解器在每圈的每个状态上，对全部配方重新生成进站分支。对于同圈、相同已用配方位掩码和饱和 stint 计数的两个状态，进站后的目标状态完全相同，且支付相同进站损失。因此，已经有更低或相等完成圈累计成本的来源时，后一个来源的进站分支不可能更新目标成本或父指针。

现在只为每组新出现的严格最低成本生成进站分支，并在该次展开中复用一次进站成本计算。所有留场分支仍保留，因为不同胎龄的未来成本不同。原状态遍历、转移先后顺序和严格小于比较保持不变，保留原有平局选择；没有改用“最少进站”等新目标。

这一规则利用的是当前共享进站损失语义。若未来加入来源状态相关的损失或额外资源，必须重新证明分组有效。最坏复杂度仍为 O(N S (C+1))，没有声称改变复杂度阶；每圈新增的组内最小值表上界为 O(2^C K)。

## 对照实验

基准脚本为 `scripts/benchmark_solver.py`。改动前源码保存为 `output/algorithm-optimization-20261107/reference/solver.py`，SHA-256 为 `15970a340627445d8a8bae1937ff7dff5482c75a5ffdf9ad441a1c5caa5c7805`。它与新版在同一进程、同一模型和约束下比较。

- 固定随机种子 20261107，400 个案例，完整结果逐项一致，包括总用时、进站圈、配方顺序、stint 长度及不可行异常类型/信息。
- 其中 388 个可行、12 个不可行；包含任意配方名称和顺序、非单调正圈时、零进站损失、非对称胎龄限制、指定起步配方、不同最少 stint 数、浮点近邻及大进站损失舍入。
- 新增 25 个小规模随机案例用独立穷举分段与配方分配求最优值，不以旧求解器作为唯一正确性依据；另加确定性平局路径回归。

计时使用原有 `synthetic_laps(seed=42)` 拟合模型，在本地 Windows 11 / Python 3.13.5 上执行。每种方法先热身两次，再交替顺序各测九次，以下为中位数：
