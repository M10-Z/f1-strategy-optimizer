# 方法与局限

[English](methodology.md)

## 状态与终点语义

第 L 圈开始时的状态为 `(compound, age, used_mask, capped_stint_count)`，分别表示配方、胎龄、已用配方掩码及截断的赛段数。胎龄用于计算即将行驶这一圈，第一圈胎龄为 1；累计成本不含第 L 圈。计入这一圈后：

1. 若为最后一圈，检查最少配方和赛段要求，直接结算。
2. 否则在允许时使用胎龄加 1 继续行驶，或在第 L 圈末支付进站损失，第 L+1 圈换成胎龄 1。允许更换同配方新胎。

新配方只有在必然产生实际行驶圈的转移时才进入掩码。终点不存在进站转移或零圈赛段。最大胎龄限制实际行驶胎龄，不限制虚构的赛后胎龄。赛段计数达到最低要求后不再增加，因为更大值不影响后续可行性；轮胎库存需要额外状态，目前未实现。

求解器缓存各配方和可达胎龄的成本，检查正值和有限性，并重建完整策略。独立评估器检查策略并重新求和；测试使用独立的整数划分与配方组合穷举器核对最优值。并列结果按模型配方和状态插入顺序确定，不额外优化进站次数。

## 复杂度

令 N 为圈数、C 为配方数、A 为最大胎龄、K 为最少赛段数。每圈状态上界为 S = C A 2^C K，每个状态最多 C+1 个转移。除模型预测外，时间复杂度为 O(N S (C+1))。滚动成本表占 O(S)，父指针占 O(N S)，因此总内存为 O(N S)。C=3 时可以省略常数，但保存全部父指针仍保留 N 因子。

## 衰减估计

拟合目标为观测圈速加上 `fuel_gain_per_lap * (LapNumber - 1)`。按年份、车手和赛段分组，对特征 `(age-1, age²-1)` 及目标进行组内中心化，再用最小二乘估计共享斜率。基准圈速为各组残差基准中位数的中位数。秩不足时明确失败。

这种方法减少组间截距混杂，但不能确定因果衰减；配方选择、交通、赛道演化、燃油假设和驾驶行为仍有限制。

有效衰减增量是原始拟合增量、零和配置的线性衰减下限的离散累计最大值，因此包括观测胎龄之外也保持非递减。可选温度因子只乘衰减增量，不乘整圈基准，并限制在 [0.5, 2.0]。系数和上下界都是建模选择，尚非验证过的物理定律。配方间隔为 0 时不强制快慢排序；正值则显式启用排序先验。

## 验证与比较

回测留出一个年份，只使用更早赛季训练，忽略更晚数据。用参考温度预测与燃油修正后的留出观测比较，报告 MAE、RMSE、有符号偏差及超出训练胎龄范围的数量。缺失训练配方会明确报告，不会偷偷使用测试集拟合。

独立 `backtest` 的清单、模型图及外推标记均使用相同的早年训练模型，不拟合留出或未来圈速，清单中的角色为 `holdout_training`。`demo`/`optimize` 即使指定 `--holdout-year`，仍保留角色为 `exploratory_all_input` 的全部输入探索模型；这类运行的 `backtest.json.model` 是独立的训练集验证模型。

报告的 `data_split` 记录训练/留出样本数和被忽略的未来样本数/年份；`coverage` 记录可评估和无训练模型的留出圈数。配方误差只适用于可评估样本，缺失模型不能视为零误差。零圈可评估的报告只说明覆盖情况，不是测得的预测精度。导出的 `laps.csv` 保留所有规范化输入行，并分别记录来源文件哈希与规范化数据哈希；该文件并非纯训练集。

每个可评估配方另设一个常数基线：仅使用训练年份该配方燃油修正圈速的中位数，不建模胎龄响应。基线与拟合模型使用相同留出样本及相同燃油先验，报告 MAE/RMSE/偏差及 `mae_difference_vs_baseline_seconds`；差值为负表示拟合模型误差较低。这一比较不校准燃油先验，也不建立因果效果。

情景比较会在同一个情景下分别评估原始策略与重新优化策略。仅比较不同环境下的总时间不能证明策略改进。强制起始配方会增加限制，因此可能比自由选择更慢。已知未来低进站损失属于完全信息情景，不能解释为在线或随机策略。本项目不声称提供置信区间或校准概率；真实策略效果还需比赛模拟和外部验证。
