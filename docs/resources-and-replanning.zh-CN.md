# 资源约束、规则与滚动规划

[English](resources-and-replanning.md) · [多车模型](competition.zh-CN.md)

保留首版 `PitAction`、`candidate_actions` 和 CLI 输入；新增字段均可选。旧快照的库存
明确标为 `unspecified_unlimited`，不能据此声称资源可行。情景权重没有经验概率校准。

## 库存与规则

- `tyre_inventory` 是不含当前装车轮胎的备用**新胎套数**。空字典或缺失配方表示零套；
  每次换胎消耗一套，同配方更换也消耗。拆下的旧胎不回库，尚无逐套身份及旧胎重用。
- `used_compounds` 记录本场已用配方；当前轮胎跑过一圈或输入胎龄大于零时计入。
  `pit_stops` 是本场此前总进站次数，需独立于可能不完整的 `observed_pits` 提供，避免重复
  累加。滚动状态持续保留库存、使用历史和次数。
- `CompetitionRules` 记录赛季、赛事、版本、来源及来源状态。启用约束时必须匹配快照
  的赛季/赛事。支持干胎种类数、至少一种指定干胎、允许配方、最低进站数、最大行驶胎龄。
  可配置的湿地豁免只作用于干胎要求，必须实际使用半雨/雨胎；下雨本身不触发豁免。
- 约束检查覆盖全部车辆。任一情景违反库存或规则，就拒绝整个候选并记录首次失败；
  不删除失败情景后重新加权。没有可行候选时不推荐，也不自动放宽规则。

2026-10-17 核对了 [FIA 2026 运动规则 Section B Issue 09（2026-10-01）](https://www.fia.com/system/files/documents/fia_2026_f1_regulations_-_section_b_sporting_-_iss_09_-_2026-10-01.pdf)
B6.3.6（第 59 页）：干胎义务与实际使用半雨/雨胎有关。B6.3.2 的使用时点比本模型逐圈
记账更细；暂停例外、B6.3.7 湿地起步指令和赛事指定配方未实现。没有自动套用官方规则。
示例最低二停是**合成研究假设**，不代表全球统一或摩纳哥规则；来源状态也不等于认证。

## 有界二停与可见状态重规划

`candidate_plans` 枚举零、一、二停。L 个边界、C 种配方的网格上限为
`1 + L*C + L*(L-1)/2*C*C`；超过候选上限（默认 500）会在枚举前失败。
规划还限制候选乘情景数（默认 2000），记录实际仿真次数、可行数及耗时。
首版行动保留 schema 1；新 `PitPlan` 使用 schema 2，并统一提供 `stops`。

`rolling_plan` 的信念回调只得到当前观测和此前进站。每圈重新生成相对时间网格，
只执行推荐中“当前边界”的动作，推进一圈后丢弃后续计划并重新规划。
实际未来路径仅仿真器持有；CLI 信念来自最初声明的假设，移除过去事件，不读取实际未来
也不据此更新权重。外部 Python 回调仍须如实管理来源，不能在闭包中偷看历史未来。

每次决策记录可见条件/库存、假设、计划、规模与耗时。单轮和总仿真预算、决策次数共同
限制计算；耗尽预算、无可行计划或实际约束失败时保留最后验证过的状态，明确未完成。
CLI 仍写出证据并返回状态码 2。有限网格可能漏掉其他可行方案，不保证全局自适应最优。

## 同队进站与合作目标

相同非空 `team` 共用本决策点的维修资源，按车辆到达间距排序。
等待为 `max(0, 前车服务完成时点 - 到达时点)`。`pit_service_time` 是资源占用时间，
**已经包含于净进站损失**，仅将额外等待加入用时；等待不按 SC/VSC 折扣。默认占用为零
兼容旧行为。不同车队独立；不模拟维修区几何、跨圈资源占用和长时间维修。

默认优化自车名次；`team_rank_sum` 优化指定车队名次之和，依次以最差得分、自车平均名次、
更少进站和标签打破平局。只选择自车方案，队友仍按给定策略行动，不是双车联合搜索、
车队指令或积分优化。对手同时行动仍然不可见。

## 示例与证据

```sh
f1-race-plan --scenario examples/competition-resources.json --output-dir output/resources-demo
```

完全合成的四车示例剩余 8 圈，配置有限库存、研究规则及四个用户加权情景。
2026-10-17 在 Python 3.12.14 本地运行：初始 67 个候选，实际仿真 211 次，48 个可行、
19 个拒绝，耗时 0.0700 秒；滚动 8 次决策、572 次仿真，耗时 0.1459 秒，完成第 53 圈。
这是单次机器观测，不是性能保证。初始推荐第 47 圈后换 HARD，加权自车名次 2.5、车队
名次和 6.5；滚动过程可以改变方案。独立小场景测试则必须并实际选择二停。

回归覆盖库存不足、实际湿胎使用、历史资源、规则范围、二停、同队排队与合作、慢车守位、
对手反制导致“自身用时更短但名次更差”，以及未来事件未观察前行动一致。
这些是**软件行为证据，不是真实预测精度或策略收益**。
完整检查见[本轮验证记录](resources-validation-2026-10-17.md)。
