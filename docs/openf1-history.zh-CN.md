# 免费 OpenF1 历史数据面板

这是独立的赛后历史观测浏览，不是新的预测模型，也不会改写已有冻结研究工作台。

## 使用

启动原工作台：

```sh
python -m f1_strategy_optimizer.workbench
```

打开本地页面的 OpenF1 历史数据区域，选择年份、点击加载比赛列表，再选择比赛和车手。首次打开页面不联网；用户开启加载后，切换比赛自动取车手、切换车手自动取圈时和stint。旧冻结工作台仍可完全离线使用。

[OpenF1 官方文档](https://openf1.org/docs/) 说明2023年以来历史数据可免费、免认证访问，实时数据需要订阅。本功能不配置账号/凭据、不订阅、不连接真实流、不上传数据，也不部署到外网。

## 边界

- 只请求固定 `https://api.openf1.org/v1/` 的 sessions、drivers、laps、stints。
- 只接收明确数字选择器，拒绝 latest、任意URL、重复/多余参数和无效编号。
- 仅允许正式Race且已结束至少24小时的会话，取消、未来和仍在进行的会话不可取比赛数据。
- 2024西班牙/匈牙利/比利时/荷兰封存验证赛事被阻止；已知会话编号在任何网络请求前拒绝。年份列表只读赛事元数据并显示禁用原因，不读取这些赛事的车手/圈时/轮胎数据。
- 不自动将历史下载加入预测、拟合、模拟、揭晓或独立验证。该面板会显示赛后结果，不能把看过的数据再称未触碰留出集。
- 无自动重试或替代域名，重定向拒绝。网络/格式失败明确显示，不构造假数据。

## 请求和缓存预算

每个工作台服务实例每秒最多1次请求、每分钟最多30次；最多2MB原始响应，sessions≤100、drivers≤40、单车laps≤500、单车stints≤100条。连接/套接字超时12秒；正文分块读取另有12秒检查期限。内存缓存最多64项/16MB原始大小，默认有效期1小时。

选择车手时只拉取该车手的laps/stints，而不下载整场遥测。会话和车手元数据通常命中缓存；缓存为空直接调用history最多四次顺序请求。所有接口核对session_key/meeting_key，历史单车数据另核对driver_number；重复圈号、负/非有限圈时会拒绝，缺失圈时保留null。

如果同一个查询之前成功缓存、但过期后拉取失败，可以明确标记 stale_fallback 并保留旧收据时间。绝不拿其他比赛/车手缓存替代。缓存只在当前服务内存，不跨重启持久化；关闭服务后仍可使用随包的离线冻结样例。达到速率上限时返回429，让用户稍后重试，不无限后台轮询。

## 时间含义和可审计信息

- lap.date_start等是提供方归档的历史事件时间，可能包含赛后修订；不是当年的消息发布时间。
- receipt.received_at_utc 是**本次HTTP正文读取完成后的本地UTC采样**，绝不写回历史事件，也不当作当年接收时间。不是首字节/网卡到达时间；系统时钟精度未知。
- 每个组件收据包含请求开始UTC、读取完成UTC、单调耗时、HTTP状态、URL、字节数和原始正文SHA256。SHA256仅用于一致性，不认证提供方身份或消息发布时间。
- 顶层received_at_utc/retrieved_at_utc保守显示组件中最早接收时间；latest_response_received_at_utc和receipts保留每次实际拉取时间，防止仅刷新元数据就把旧圈数据冒充新数据。
- served_at_utc是本次页面响应时间，不是数据生成时间。缓存命中/失败回退不会刷新旧的原始收据时间。

## HTTP接口

```text
GET /api/openf1/sessions?year=2023
GET /api/openf1/drivers?session_key=7953
GET /api/openf1/history?session_key=7953&driver_number=16
```

响应含source和limitations。history另含session、driver、laps、stints，并固定 `mode=historical_observations_only`、`forecast_created=false`、`source.live=false`、`source.availability_basis=post_event_download`。错误状态400为选择/策略拒绝，429为速率，502为网络/上游内容失败。静态面板与接口同源，不让浏览器直接持有凭据或任意访问外部域名。

## 已执行验收

2026-11-04普通公共API调用取得2023赛事列表23项、巴林7953的20名车手，以及Leclerc（16）40圈/3个stint。这里的圈数是该车手归档记录数量，不暗示其完成整场比赛。响应保存在本轮本地验收输出，未改变随包冻结样例。

自动测试使用可控网络替身覆盖无联网初始化、历史事件/当前接收时间区分、缓存隔离与失败回退、封存/未来赛事拒绝、响应限额、重定向、速率、车手/赛事标识、缺失值、错误参数，以及不会新增任何预测/模拟/揭晓任务。

网络并发采用独立单飞门禁：上游请求进行时，新的未缓存请求立即返回429而不排队；缓存命中不等待上游I/O。缓存锁仅保护短暂读写。stint可选字段缺失保留null；已提供的编号/胎龄必须是范围内整数，开始圈不得晚于结束圈，配方必须是非空字符串，重复分段编号拒绝。
