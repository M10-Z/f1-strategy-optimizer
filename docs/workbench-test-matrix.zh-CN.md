# 工作台参数与组合测试

本轮只使用随包的 2023 巴林开发样本（3 个历史截止点、20 位车手），不访问留出集、实际结果、揭晓文件或外部数据源。测试“程序按声明规则运行或明确拒绝”，不验证预测精度。

## 组合覆盖

`tests/test_workbench_parameter_matrix.py` 用确定性的贪心覆盖数组，从10个离散参数域生成17组配置，覆盖全部 **326 个两两取值对**。这些离散值的完整笛卡尔积为 **15,552 组**，本轮没有运行全部组合，也没有声称三因素以上交互均覆盖。

连续值无法穷举，本轮使用代表值、合法边界、非法边界、缺失值和非有限数值。成对测试仅使用第一快照 Leclerc 的5车模型，不能理解为全部60个选择都跑过17种组合。

每组测试显式构造与测试时域相符的候选和情景，湿地损失统一设为假设的5秒；这只是测试夹具，未校准，也不会改写用户计划。真实页面遇到冲突时只提示用户调整，禁止静默删除候选或补造参数。

`tests/test_workbench_horizon_matrix.py` 穷举 60 个选择 × 2 个目标 × 4 个时间模式，共480项。随包归档缺少验证过的接收/目标边界，全部正确保持数值操作预测不可用；这不等于没有历史圈时估计。

## 可重复运行

```sh
.venv/bin/python -m pytest tests/test_workbench_driver_matrix.py tests/test_workbench_parameter_matrix.py tests/test_workbench_horizon_matrix.py -q
node --check src/f1_strategy_optimizer/workbench_static/app.js
node scripts/test_workbench_frontend.mjs
```

前端脚本还检查未触发 `change` 时提交采用当前输入、非法输入不沿用旧值、旧导出失效、快照/车手乱序响应、空值显示、圈时格式、结束圈与候选/事件/对手窗口冲突、湿地假设缺失。

## 限制

- 自动化直接调用 Python API / 引擎，前端脚本使用轻量DOM，不等于所有组合都经过真实浏览器点击。
- 浏览器人工验收单独记录，只覆盖实际执行的路径与窗口尺寸。
- 高级JSON可包含任意结构和连续参数，本轮不是所有JSON内容、输入长度或硬件/浏览器组合的穷举。
- 历史样本已经被观察；这轮测试不是独立模型验收，没有新增实时来源，也不改变“精度未通过”的结论。

## 60 个选择的实际结果

新增车手矩阵测试71项通过，其中含60次真实独立进程策略任务、输入/文件访问防护检查。预测共37个有条件估计、23个明确不预测；默认策略29个可行、31个因缺少输入明确拒绝。

| 截止时间 UTC | 圈时有值 / 暂不预测 | 默认策略成功 / 明确缺值拒绝 |
| --- | --- | --- |
| 15:18 | 20 / 0 | 18 / 2 |
| 15:38 | 17 / 3 | 11 / 9 |
| 16:13 | 0 / 20 | 0 / 20 |

每个选择另检查附近、全部20车、自选仅当前车手、自选当前车手加一名对手，共240个参与车映射，并重复生成验证确定性。具有当前车手的圈时估计，不代表默认策略一定可运行：队友或附近对手缺值仍会阻断。未用假值替代这些缺失数据。

每个选择的具体缺失字段和拒绝原因可用 `pytest -q -s tests/test_workbench_driver_matrix.py` 查看。矩阵测试同时限制父进程与模拟子进程的文件读取，只允许随包目录、决策、假设与前缀上下文；没有读取揭晓、结果或留出文件。

## 本轮发现并修复的前端问题

- 湿地选项缺少各轮胎配方的损失参数时，原本进入后台后才返回英文错误；现在先给出中文说明，要求用户显式填写，不自动补值。
- 提交前同步数值时，未编辑的高级对手计划可能被简化。现在只有可见计划圈或策略类型真的变化才更新，保留原多停计划及自定义响应阈值；已有专项回归。
- 页面初次加载完成前的程序化参数修改曾触发 `null planning`。依赖区域现在初始为不可交互状态，事件处理器也检查数据是否就绪；未载入时不会写入参数或报此错误。

在这些变化之外，缺值导致模拟拒绝、湿地需显式参数、缩短模拟时域需同步调整计划，均是有效限制，不通过填造数据或删计划让测试“通过”。

在最后一次初始化保护修复之后，全量Python回归 **1013 passed，31条既有NumPy/Pandas弃用警告，48.56秒**。新增三个矩阵文件共636项；其余为既有回归。Ruff检查与格式检查通过，JS语法和DOM/异步/参数边界回归通过。
